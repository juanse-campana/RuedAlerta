# Habilidades del frontend

Directorio reservado para documentar habilidades específicas del frontend cuando se identifiquen necesidades reutilizables. No hay habilidades propias definidas por ahora.

Una skill ejecutable debe crearse siguiendo el formato y la ubicación reconocidos por el entorno de agentes. Guardar documentación aquí no instala ni activa una skill automáticamente. Las skills compartidas del proyecto se ubican en `.agents/skills/` desde la raíz del repositorio.
